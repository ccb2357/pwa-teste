# Visão

PWA Framework é uma fundação reutilizável para criar PWAs independentes. O primeiro checkout local fica em C:\var\www\pwa-teste; seu nome público inicial é PWA Framework, derivado do arquivo central. Não há produto de negócio definido.

Inclui bootstrap portátil e idempotente, configuração central por ambiente, Laravel/MySQL, Framework7 Vue, Hello com componentes interativos, design system, PWA, testes e documentação de continuidade. Cada clone recebe a base pronta e executa o inicializador; não repete as sprints.

Não inclui login completo, regras de negócio, integrações bancárias, persistência de dados do formulário Hello, edição offline/sincronização de registros ou pagamentos. Sanctum/sessão/CSRF ficam preparados para futuros fluxos.

Critérios de construção concluída: Hello interativa e status real, backend/banco integrados, build/PWA verificados, testes aplicáveis, bootstrap funcional, dois clones isolados e reexecução validados. Aparelhos reais e produção exigem evidências específicas. O [README](../../README.md) rege o escopo detalhado; andamento somente em [MEMORY](../../MEMORY.md).
